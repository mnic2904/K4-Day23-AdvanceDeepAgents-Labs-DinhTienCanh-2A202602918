# Survey of Efficient Inference and Small Language Models

## TL;DR
- Small Language Models (SLMs) like Phi-3-mini (3.8B parameters) can achieve competitive performance on reasoning benchmarks such as MMLU (69%) despite limited size, typically utilizing large amounts of synthetic and heavily filtered web data [1][2].
- Modern architectural innovations such as grouped-query and sliding window attention significantly reduce memory overhead and latency, making SLMs practical for edge deployments [3].
- Inference latency is vastly improved through techniques such as speculative decoding, which uses a smaller model to draft future tokens and verifies them with a larger target model, commonly achieving 2x to 3x speedups [4][5].
- Deployment efficiency often relies on frameworks suited to the hardware: vLLM excels in large-scale multi-user environments with its PagedAttention architecture, whereas llama.cpp is vital for offline and local inference through CPU-friendly GGUF quantization [6][7].
- Edge computing frequently depends on 4-bit NormalFloat (NF4) INT4 quantization to fit SLMs onto devices like Nvidia Jetson edge platforms [8][9].

## Background
The rapid progression of large language models has demonstrated remarkable success in complex reasoning, generation, and coding tasks. However, this scale introduces significant bottlenecks: the substantial memory required to host billions of parameters and their expanding Key-Value (KV) caches, combined with the inherently sequential memory bandwidth issues caused by autoregressive decoding [10][11]. In response, the development focus has bifurcated. While one trajectory seeks to optimize inference operations for the largest models via systems and algorithmic breakthroughs, another heavily invests in Small Language Models (SLMs) to bypass computational limits through architectural and data-centric efficiencies [10][2][12]. This survey explores the interplay between efficiency techniques and the rising capability of SLMs.

## Advancements in Small Language Models (SLMs)
The creation of robust SLMs involves aggressive optimization of both training data and model architecture. The Phi-3-mini model, running locally with only 3.8 billion parameters, reaches a score of 69% on MMLU and 8.38 on MT-bench, rivaling significantly larger architectures such as GPT-3.5 and Mixtral 8x7B [1]. Its success fundamentally depends on vast, high-quality pretraining datasets composed of carefully filtered web text and synthetically generated data [1]. 

Equally important are architectural adjustments. Mistral 7B incorporates grouped-query attention and sliding window attention, ensuring highly efficient localized inference that enables it to outperform many counterparts [3]. Open-source model families like Gemma have similarly demonstrated that models built under ten billion parameters can outperform previously dominant massive architectures in text-based tasks [13]. Furthermore, these architectures are highly adaptable; the context window of Llama-3-8B-Instruct was successfully expanded from 8K to 80K tokens using minimal QLoRA fine-tuning, demonstrating the flexibility and efficiency of compact designs [14].

## Efficient Inference Mechanisms
Whether deploying large foundation models or optimized SLMs, specific inference mechanics are required to alleviate memory constraints [15][10]. 

### Quantization and Pruning
Quantization drastically reduces memory utilization and bandwidth consumption. Weight-only quantization formats like AWQ and GPTQ pre-compress model weights offline, decompressing them to FP16 just-in-time during the memory bandwidth-constrained decoding phase [10]. Further addressing memory bottlenecks generated by long contexts, KV-Cache Quantization methodologies such as KVQuant and KIVI aggressively compress the cached attention keys and values into 2-bit or 4-bit precision [11]. For reducing parameter counts outright, unstructured pruning utilizing one-shot compression algorithms provides tangible acceleration without needing extensive retraining, though it does demand considerable compute resources upfront [5].

### Speculative Decoding
The sequential nature of autoregressive generation represents a core latency issue, as only one token is generated per forward pass. Speculative decoding dramatically alters this dynamic by changing generation into a parallelizable "draft-then-verify" procedure [4]. A smaller, highly efficient drafting mechanism outputs numerous potential tokens in sequence, which are then verified simultaneously by the heavier target model [5]. Because the verification pass theoretically preserves the target model's output distribution exactly, speculative decoding trades spare parallel compute capacity for memory bandwidth time savings, effectively achieving 2x to 3x speedups in inference [5][11]. Approaches like Tree-structured drafting (used in Sequoia and EAGLE-2) further optimize this by drafting multiple alternative continuation branches, minimizing wasted cycles when a primary draft token is rejected [11].

## Deployment Frameworks and Edge Hardware
The software frameworks handling inference significantly influence deployment viability across different hardware setups. For enterprise-level, high-concurrency cloud environments, vLLM leverages PagedAttention to manage the KV cache dynamically, providing 2x to 4x better throughput than naive implementations [7]. High-concurrency benchmarks show vLLM processing up to 35 times more requests per second than llama.cpp under heavy multi-user loads [6]. Conversely, when structured output extraction (e.g., JSON schemas) is strictly necessary on individual servers, Hugging Face Text Generation Inference (TGI) provides an advanced structured decoding stack specialized for single-GPU environments [7].

For private, offline, and mobile hardware, llama.cpp dominates the landscape [6]. Using highly optimized pure C/C++ backends and the GPT-Generated Unified Format (GGUF), llama.cpp allows massive parameter models (up to 72B) to execute functionally on consumer hardware by employing aggressive low-bit quantization, such as 4-bit INT4 [7].

These software solutions synergize directly with hardware-co-designed peripheral language models (PLMs) tailored for ubiquitous edge devices [12]. The deployment of 4-bit NormalFloat (NF4) INT4 quantization is critical for fitting models onto constrained edge chips [8]. When combined with Grouped-Query Attention—which reduces the KV cache size—a model like Phi-3-mini executes comfortably within a 2.8 GB VRAM footprint, providing swift time-to-first-token times (e.g., 0.2 seconds) on consumer architectures [8]. Similarly, SLMs ranging from 1 to 3 billion parameters represent an optimal balance for local agentic workflows; 3B models like xLAM-2 run smoothly on platforms like the Nvidia Jetson Nano, bypassing the severe capability degradation often found in sub-1B architectures [9].

## Trends and open problems
The transition towards Small Language Models and robust efficient inference tools continues to redefine artificial intelligence deployment. As evident from models like Phi-3 and families like Gemma, synthesizing synthetic training data is the cornerstone of generating SLMs that compete with legacy, resource-heavy LLMs [1][13]. 

However, open challenges persist. While speculative decoding proves transformative for pure inference speed, the computational overhead of training perfect drafter models or designing flawless verification strategies remains non-trivial [4]. Likewise, video language models (VideoLLMs) still incur staggering computation costs relative to frame count and long-context multimodal inputs, leaving deployment on mobile and constrained hardware as largely unresolved [15]. Furthermore, although edge deployments utilizing Direct Preference Optimization (DPO) and GGUF demonstrate remarkable progress natively tuning SLMs for agentic APIs [9], navigating the precise trade-off between quantization severity and multi-turn conversational competence remains an active area of investigation [8][9].
